# 工作台 UI 规范（钉钉 / 智能体 / 项目组）

所有注入 Codex Desktop 的界面都要像 Desktop 原生的一部分。本规范是验收标准；有冲突时以本规范为准。

## 1. 基础规则

- **只用 Desktop 的设计变量**，不手写颜色、字号、圆角：`--color-token-*`（文字 `text-primary/secondary/tertiary`、表面 `main-surface-primary`、背景 `bg-primary`、描边 `border-default`、悬停 `list-hover-background`、链接 `text-link-foreground`）、`--font-text-{xs,sm,md}-{size,line-height,weight}`、`--radius-*`。浅色/深色自动跟随，不写两套颜色。
- **字号层级只有三级**：标题 `text-md`（16px，600）、正文 `text-sm`（14px，400）、辅助 `text-xs`（12px，`text-tertiary`）。一屏内不出现第四种字号。
- **间距用 4 的倍数**：行内 8、控件间 8/12、区块 16/24。列表行高 56（会话）/ 36（菜单）。
- **按钮**：主操作最多一个，用 Desktop 原生按钮样式；次要操作用无边框文字按钮或图标按钮（带 tooltip）。禁止实心黑底大按钮、一排并列的描边按钮。
- **说明文字**：每个区块最多一行辅助说明；实现细节（文件路径、"由单独服务执行"之类）不出现在界面上。
- **状态齐全**：加载（骨架行，不用转圈文字）、空状态（一句话 + 可选一个操作）、错误（一句中文原因 + 重试），不显示英文原始报错。
- **动效**：悬停/选中 120ms 背景过渡；不做大面积动画。

## 2. 钉钉页

钉钉是聊天应用，不是设置表单。**占满工作台内容区**（左右贴边、上下撑满），不套设置页的居中最大宽度和卡片外框。

### 布局
```
┌──────────────┬──────────────────────────────────────────┐
│ 🔍 搜索       │ 会话名 · 单聊/群聊              [嵌入] [⋯] │
│ 未读 ▾        │──────────────────────────────────────────│
│ ┌──────────┐ │            ── 11月5日 ──                  │
│ │头 名称  时间│ │  头 吴菁 17:48                            │
│ │像 摘要  (3)│ │     消息气泡                              │
│ └──────────┘ │                         我的消息气泡 ✓      │
│   …          │──────────────────────────────────────────│
│              │  输入框（自动增高）                    ➤   │
└──────────────┴──────────────────────────────────────────┘
```
- 左栏 280px，背景 `bg-primary`；右栏 `main-surface-primary`；中间 1px `border-default`。
- **会话行**（56px）：36px 圆角头像（首字 + 由会话 id 稳定生成的柔和底色，不是统一亮蓝）；第一行 名称（`text-sm` 500，单行省略）+ 右侧时间（`text-xs` tertiary，今天显示时:分，昨天显示"昨天"，更早显示月/日）；第二行 最近消息摘要（`text-xs` secondary）+ 右侧未读红点数字（免打扰时灰色小圆点，不显示"免打扰"文字）。选中行用 `list-hover-background` 加深一档，不用蓝底。
- 列表标题只有一个小分组标签（"未读" / "最近回复"），不出现"钉钉登录 下拉框"这类设置项；连接/默认机器放到页面右上角 ⋯ 菜单里。

### 消息区
- **打开会话时停在最新消息（底部）**；向上滚动到顶时自动加载更早的一页（顶部显示骨架行），加载后保持当前阅读位置不跳动。首次只取最近 30 条。
- 按日期插入居中分隔（"今天"/"昨天"/"11月5日"）；同一发送人 3 分钟内的连续消息合并，只在第一条显示头像和名字。
- 他人消息靠左带头像，气泡 `bg-primary`；我的消息靠右，无头像，气泡用浅蓝强调色（`charts-blue` 12% 混合），文字主色。气泡圆角 12，内边距 8×12，最大宽度 70%。
- 不支持的消息类型显示一行灰色摘要「[卡片] 标题 · 在手机上查看」。
- 有新消息到达且用户不在底部时，右下角浮出「↓ N 条新消息」。

### 搜索
- 搜索框在左栏顶部。输入后**左栏列表被搜索结果替换**（右侧聊天保持不动）：分两组「会话」「聊天记录」，命中关键字高亮；点会话结果打开该会话，点聊天记录结果打开会话并滚动高亮到那条消息。清空或按 Esc 回到未读列表。
- 搜索中显示骨架行；无结果显示「没有找到相关会话或消息」。

### 嵌入到对话
- 头部只有一个「嵌入会话」图标按钮（tooltip）。
- 多选：悬停消息时左侧出现复选框；勾选任意一条进入选择状态，底部输入框位置换成选择条「已选 3 条 · 嵌入到对话 · 取消」。嵌入后关闭页面并回到原输入框，chip 已插入。

### 输入框
- 与 Codex Composer 一致的圆角输入框，自动增高（最多 6 行），右侧圆形发送图标按钮；Enter 发送、Shift+Enter 换行；占位「发消息给 {会话名}」。发送中气泡显示半透明 + 小转圈，失败显示红色感叹号可点重试。

## 3. 智能体页

用 Desktop 设置页的原生列表行风格，不用卡片堆叠。
- 页头：标题「智能体」+ 右侧一个「新建」按钮；一行说明「智能体是可被委派任务的 Codex 角色」。
- 列表行：名称（500）+ 模型·推理强度（tertiary）；第二行描述单行省略；行右侧悬停时出现 ⋯ 菜单（编辑 / 复制 / 删除）。点击行打开编辑。
- 编辑：右侧抽屉或居中对话框，字段分组：基本（名称、描述）、模型（模型下拉 + 推理强度分段控件）、指令（等宽多行编辑器，可伸缩）。保存/取消在底部右侧。
- 「钉钉监听」单独一个设置分组：开关行（主开关）；展开后：处理类型（三个复选行）、匹配阈值（滑块 + 数值）、回复位置（分段控件：群内 / 私聊）、参与的智能体（复选列表）。审批规则用一行灰色提示放在分组底部。不出现文件路径和实现说明。

## 4. 项目组「+」与添加机器

- 「+」菜单：上半部分按机器列出组内已有的项目（与现在一致）；底部固定一行「添加机器…」（带 + 图标），**不平铺每台机器 × 每个 Agent**。
- 点「添加机器…」打开二级菜单，样式与 Composer Agent 菜单的「其他机器」一致：每行 服务器图标 + 机器显示名 + 在线状态点；已在组内的机器不显示；离线机器置灰。
- 选中机器后：在该机器创建 `~/Documents/ChatGPT/<项目名>`、加入同组、打开该机器上的空白新对话（默认 Agent，可在 Composer 里再切换）。全程一次点击，过程中菜单行显示转圈，失败行内显示中文原因。

## 5. `@` 入口

- 原生 `@` 菜单里只追加**一行**「钉钉」（钉钉图标 + 「打开钉钉工作台」辅助文字），不在菜单里列会话。选中后打开钉钉页并记住来源 Composer。
