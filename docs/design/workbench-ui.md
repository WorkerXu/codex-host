# 工作台 UI 规范（钉钉 / 智能体 / 工作文件夹）

所有注入 Codex Desktop 的界面都要像 Desktop 原生的一部分。本规范是验收标准；有冲突时以本规范为准。

## 1. 基础规则

- **只用 Desktop 的设计变量**，不手写颜色、字号、圆角：`--color-token-*`（文字 `text-primary/secondary/tertiary`、表面 `main-surface-primary`、背景 `bg-primary`、描边 `border-default`、悬停 `list-hover-background`、链接 `text-link-foreground`）、`--font-text-{xs,sm,md}-{size,line-height,weight}`、`--radius-*`。浅色/深色自动跟随，不写两套颜色。
- **字号层级只有三级**：标题 `text-md`（16px，600）、正文 `text-sm`（14px，400）、辅助 `text-xs`（12px，`text-tertiary`）。一屏内不出现第四种字号。
- **间距用 4 的倍数**：行内 8、控件间 8/12、区块 16/24。列表行高 56（会话）/ 36（菜单）。
- **按钮**：主操作最多一个，用 Desktop 原生按钮样式；次要操作用无边框文字按钮或图标按钮（带 tooltip）。禁止实心黑底大按钮、一排并列的描边按钮。
- **说明文字**：每个区块最多一行辅助说明；实现细节（文件路径、"由单独服务执行"之类）不出现在界面上。同一屏不重复解释同一件事；用户文案不出现 Host、CLI、Thread、SSH、RPC、回调、置信度等实现词。
- **状态齐全**：加载（骨架行，不用转圈文字）、空状态（一句话 + 可选一个操作）、错误（一句中文原因 + 重试），不显示英文原始报错。
- **动效**：悬停/选中 120ms 背景过渡；不做大面积动画。

## 2. 钉钉页

钉钉是聊天应用，不是设置表单。**占满工作台内容区**（左右贴边、上下撑满），不套设置页的居中最大宽度和卡片外框。打开钉钉页时隐藏左侧设置导航，只保留顶部关闭/返回。

### 布局
```
┌──────────────┬──────────────────────────────────────────┐
│ 🔍 搜索       │ 会话名 · 单聊/群聊              [嵌入] [⋯] │
│              │──────────────────────────────────────────│
│ ┌──────────┐ │            ── 11月5日 ──                  │
│ │头 名称  时间│ │  头 林晓 17:48                            │
│ │像 摘要  (3)│ │     消息气泡                              │
│ └──────────┘ │                         我的消息气泡 ✓      │
│   …          │──────────────────────────────────────────│
│              │  输入框（自动增高）                    ➤   │
└──────────────┴──────────────────────────────────────────┘
```
- 左栏 280px，背景 `bg-primary`；右栏 `main-surface-primary`；中间 1px `border-default`。
- **会话行**（64px，左右 12px 内边距，列表左右再留 6px 让选中背景内缩）：40px 圆角方块头像（radius 10，钉钉蓝及同族变体，按会话 id 稳定选取；白字两字，群取标题去符号后的前 2 字，单聊取姓名后 2 字，纯英文取首字母），头像到文字 10px。第一行 名称（`text-sm` 400，单行省略）+「内部群」描边标签 + 右侧时间（`text-xs` tertiary）；第二行与第一行间距 4px，最近消息摘要（`text-xs` secondary，前缀「[N 条]」「[有人@我]」）。未读数显示为**头像右上角红色圆角徽标**（白字，>99 显示 99+）；免打扰会话只在头像右上角显示红色小圆点，并在第二行右端显示灰色铃铛斜线图标。选中行用 `list-hover-background` 加深一档，圆角 8，不用蓝底。
- 列表没有视图切换，也不出现"钉钉登录 / 默认机器"下拉框。⋯ 菜单只显示一行连接状态（已连接身份 / 未登录 / 无法连接，后者带重试）和刷新。
- 列表为空时整个右侧（标题、头部按钮、消息区、输入框）隐藏，只保留左栏的空状态。

### 消息区
- **打开会话时停在最新消息（底部）**；首次进入默认打开上次查看的会话（若仍在列表里），否则打开第一行；列表非空时不显示「选择一个会话」。列表只保留最近 48 小时有未读的会话。向上滚动到顶时自动加载更早的一页（顶部显示骨架行），加载后保持当前阅读位置不跳动。首次只取最近 30 条，最多保留当前会话最近 200 条。
- 按日期插入居中分隔（"今天"/"昨天"/"11月5日"）；同一发送人 3 分钟内的连续消息合并，只在第一条显示头像和名字。
- 他人消息靠左带头像，气泡 `bg-primary`；我的消息靠右，无头像，气泡用浅蓝强调色（`charts-blue` 12% 混合），文字主色。气泡圆角 12，内边距 8×12，最大宽度 70%。
- 引用回复显示灰色引用块（发送人 + 两行摘要）；`reactions` / `emotionReplyList` 显示为底部小表情计数 chip；机器人消息在发送人后加「机器人」描边标签。
- 图片用 `resourceRefs` 下载后显示（失败显示「[图片]」占位）；只在滚入可视区时加载，缩略图最大 240 px、圆角 12，纯图片消息不再套灰色气泡内边距，行移除或关闭页面时释放 object URL。文件显示文件名 + 大小 chip。
- Markdown 卡片用白底描边卡片 + 加粗标题 + 正文；正文按 Markdown 段落、引用、列表、链接和加粗渲染。原始 `<imageContent>`、`mediaId=`、`fileId:` 一律不显示。单条正文超过 8 000 字时只按纯文本截断显示，并提供「展开」。
- 有新消息到达且用户不在底部时，右下角浮出「↓ N 条新消息」。

### 搜索
- 搜索框在左栏顶部。输入后**左栏列表被搜索结果替换**（右侧聊天保持不动）：分两组「会话」「聊天记录」，命中关键字高亮。会话组先列本地未读命中，再列 `dws` 群搜索和人员搜索结果（人员即单聊），最后是消息命中的会话；不做 Gemini 分类。点会话结果打开该会话，点聊天记录结果打开会话并滚动高亮到那条消息。清空或按 Esc 回到未读列表。
- 搜索中显示骨架行；无结果显示「没有找到相关会话或消息」。

### 嵌入到对话
- 头部只有一个「嵌入会话」图标按钮（tooltip）。
- 不提供消息多选；Agent 回复里的 `dingtalk://message/...` 链接仍可跳回并高亮对应消息。

### 输入框
- 与 Codex Composer 一致的圆角输入框，自动增高（最多 6 行），右侧圆形发送图标按钮；Enter 发送、Shift+Enter 换行；占位「发消息给 {会话名}」。发送中气泡显示半透明 + 小转圈，失败显示红色感叹号可点重试。

## 3. 智能体页

用与 Desktop 原生设置一致的自适应卡片网格，不用列表堆叠。
- 页头：只有标题「智能体」，不放说明文字或按钮。
- 卡片（最小 240px，间距 16，圆角 12）：48px 程序化头像、名称（单行省略，悬停显示全名）、两行描述、底部标签（模型 · 推理强度 / 「参与钉钉」/「最近派发」）。名称允许中文、空格和任意字符，不限长度。悬停时右上角显示状态文字与 ⋯ 按钮；最后一张是虚线「＋ 新建智能体」卡片。
- ⋯ 打开锚定在按钮下方的弹出菜单：surface + 1px 描边 + 圆角 + 阴影，行高 32，删除用危险色；点击外部、Esc、滚动或窗口缩放关闭，方向键 / Home / End 可移动焦点。菜单打开期间卡片操作区保持可见。
- 删除使用页面内确认对话框（标题、一句话后果、取消 / 删除），不用浏览器原生 `confirm`；确认后卡片消失，并同时退出钉钉参与。
- 编辑：右侧抽屉，字段分组：基本（名称、描述）、模型（模型下拉 + 推理强度分段控件）、指令（等宽多行编辑器，可伸缩）、钉钉（启用开关、处理类型三个复选、回复位置分段控件，默认关 / 全选 / 群内）。每个字段的错误直接显示在该字段下方。保存按钮在底部右侧。
- 「钉钉监听」全局分组放在卡片网格下方，只放匹配阈值（滑块 + 数值，默认 0.85）和一行审批说明；不放全局开关、参与名单、全选/清空或回复位置。
- 文案面向使用者：一屏内不重复同一句说明，不出现文件路径、Host、CLI、Thread、SSH、RPC、回调、置信度等实现词。

## 4. 对话工作文件夹

- Composer 上方的「工作文件夹」chip 与机器/项目 chip 同行，显示主要目录的短名称与额外目录数量；完整路径和智能体目录能力放在 tooltip。
- 弹窗列出当前目录、项目目录和最近目录，原生风格对勾多选，选择即时生效；第一项用小标签标记「主要」，其他选中项悬停或聚焦时提供「设为主要」。始终保留至少一个目录，Esc / 点击外部关闭。
- 「添加文件夹…」使用原生文件夹选择器或切换至目录浏览子视图：顶部返回箭头、路径输入和小号主按钮「添加」，下方仅显示当前路径的子文件夹名。回车 / 添加保存后返回主视图；Esc 先返回再关闭。弹层高度最多 `min(420px, 视口高度 - 120px)`，内部滚动时保留路径栏。远程目录从对应机器只读列出，不展示协议和持久化细节。
- 已有对话使用居中细分隔提示显示简短目录名，完整路径放在 title；变更从下一轮生效。不能使用额外目录的智能体，在 tooltip 和弹窗说明只使用主要文件夹。
- 点击外部或 Esc 关闭，Esc 把焦点交回 chip；Tab、空格和 Enter 使用按钮/菜单项/输入框；上下方向键和 Home / End 导航菜单。浏览内容展开后弹窗仍保持在视口内。

## 5. `@` 入口

- 原生 `@` 菜单的「工作台」分组只追加两行：**钉钉**（钉钉图标 + 「打开钉钉工作台」）和 **Jarvis**（Jarvis 图标 + 「搜索 Bug」）。不在菜单里列会话、项目或 Bug。输入 `@` 后的文字不会触发 Jarvis 搜索。
- 选中钉钉打开钉钉页并记住来源 Composer。
- 选中 Jarvis 后同一个原生弹层切换到 Bug 搜索模式：顶部「‹ Jarvis · Bug」返回头，下面聚焦的搜索框、可删除条件 chip、结果行和键盘提示。结果行显示 `#id`、单行标题、项目名（tertiary）、状态 pill、优先级/严重程度和相对时间；加载用骨架行，空状态是「没有符合条件的 Bug」并保留 chip。Esc 或返回箭头回到原生菜单。
- 分组插在原生列表的滚动容器 `[data-mention-list-scroll-area]` 内部，与原生 section 相同的 `data-mention-section-*` 结构、分组标题和 `[data-list-navigation-item]` 按钮行，跟随原生 `aria-current` 上下键与回车；两个入口共用一个「工作台」section。原生列表不出现时不显示任何自建浮层。选中后打开钉钉页并记住来源 Composer。

## 6. 钉钉原生参照（截图在 `codexhost-pack/ui-reference/dingtalk/`，仓库外）

向原生钉钉对齐、但用 Codex 设计变量呈现的细节：
- 会话行：名称后可跟小号描边标签（如「内部群」，`text-xs`、圆角 4、`border-default` 描边、链接色文字）；摘要前缀「[7 条]」显示合并条数，@我 的会话前加红色「[有人@我]」；未读数显示为头像右上角红色圆角数字徽标，免打扰会话只显示小红点；时间：今天 `HH:mm`、昨天「昨天」、本年 `MM-DD`、更早 `YY-MM-DD`。
- 聊天头部：名称（`text-md` 600）+ 第二行灰色副标题（单聊显示对方组织/部门，群聊显示成员数），右侧只放图标按钮。
- 时间分隔：居中灰色小字，间隔超过 5 分钟插入一次（「15 分钟前」「17:48」「昨天 17:48」）。
- 我的消息：浅蓝气泡靠右，气泡下方小字「已读 / 未读」（有数据时）。
- 输入框：大圆角容器，占位「发送给 {会话名}」，底部一行工具图标（本期只需要表情以外的占位可省略），右下「发送」按钮在无内容时为禁用灰态。
- 搜索：结果按类型分组（会话 / 聊天记录），每组标题小号灰字，最多 3 条 +「查看更多」；关键字用橙色高亮（`charts-orange` 或等效变量）。本期仍显示在左栏内，不做全屏遮罩。
